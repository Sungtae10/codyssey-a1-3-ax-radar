        자주 묻는 질문

        입력한 내용이 저장되나요?

        서버에 저장하지 않아요. 진단을 위해 AI API로 전송되고, 결과는 지금 보고 있는 화면에만 표시돼요. 운영자가 알림 기능을 켠 경우에도 업종·규모·점수·단계 요약만 전달되고, 회사명과 고민 문장은 보내지 않아요. 다만 AI 제공사의 무료 등급은 입력 내용을 서비스 개선에 활용할 수 있으니 회사 기밀이나 개인정보는 적지 마세요. 과도한 요청을 막기 위해 접속 IP 는 1분 동안 서버 메모리에만 잠시 기억하고 저장하지 않아요.

        결과는 얼마나 믿을 수 있나요?

        단계와 점수는 입력한 점수로 계산한 값이라 같은 점수면 항상 같아요. 요약, 로드맵, KPI 문장은 AI가 만든 초안이라 같은 입력에도 조금씩 달라질 수 있어요. 실제 투자 결정 전에는 담당자·전문가와 검토하세요.

        진단은 얼마나 걸리나요?

        보통 5~20초 걸려요. 10초가 넘으면 "오래 걸리고 있어요" 안내가 나오고, 50초가 넘으면 요청을 자동으로 멈춘 뒤 다시 시도할 수 있게 안내해요.

        오류가 나면 어떻게 하나요?

        필수값 누락은 해당 칸에 빨간 안내가 나와요. 요청이 몰리면(429) 1분 뒤, 서버 오류(5xx)나 시간 초과는 잠시 뒤 다시 시도를 눌러 주세요. 안내 아래의 오류 코드를 알려 주시면 원인을 빨리 찾을 수 있어요.

        비용이 드나요?

        이용자는 무료예요. 운영자 쪽에서는 AI API 사용량에 따라 비용이나 사용 한도가 생길 수 있어서, 요청 중 버튼 잠금, 입력 길이 제한, 같은 곳에서 1분에 6번까지만 진단하는 제한으로 불필요한 호출을 줄였어요.

        어떤 기술로 만들었나요?

        화면은 프레임워크 없이 HTML, CSS, JavaScript로 만들었고, AI 호출은 Vercel의 Python 서버리스 함수(/api/diagnose)가 담당해요. API 키는 서버의 환경 변수에만 있고 브라우저로는 전달되지 않아요.

        소개

        왜 만들었나요?

        AI 전환을 시작하려는 제조기업이 "우리는 지금 어디쯤인가"를 빠르게 점검하도록 돕고 싶었어요. 기술경영(MOT)에서 다루는 성숙도 진단 개념을 누구나 3분 안에 써 보는 웹 서비스로 옮겼어요.
